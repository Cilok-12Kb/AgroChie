# AgroChie Web

Frontend Next.js dengan tema putih–hijau, Nunito, dashboard monitoring lahan, dan integrasi API Express berbasis cookie httpOnly. Tidak memakai fake login atau repository mock di rute aktif.

Instruksi instalasi, peta rute, serta keterbatasan model/fitur tersedia di [README root](../README.md).

Jalankan `npm ci` lalu `npm run dev -- -p 3001` (backend port 3000). Konfigurasi proxy melalui `.env.local` (contoh: `.env.example`).
